# Getting Started

## Basic Navigation

The basics are a screen reader's. Arrows move focus. Tab and Shift+Tab cycle control groups. Enter activates. Backspace is the secondary action where a control has one, usually its details (the game's "more info"). Escape backs out. Home and End jump to the ends of a list, Alt+Up and Alt+Down to the previous or next section. Typing letters searches the focused group by name.

Focus announcements are deliberately short: name, value, state, role. Everything longer a control carries, its description, keyword explanations, tooltips, waits in the buffers; see [Buffers](buffers.md).

## Keys Here

**Press F1, anywhere.** It lists the keys that do something right where you are, the most particular first: the board keys while you are on a cell, the card keys in a fight, and what Escape does on this screen. Enter on a row runs that key for you: you hear whatever the key says, then the control you were on.

That list is the reference, and it is always current. [Controls](controls.md) is the full list for when you want to see everything at once.
