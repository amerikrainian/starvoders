# Introduction

StarVoders is a screen reader and keyboard accessibility mod for StarVaders, a roguelike deckbuilder in which you pilot a mech against invaders descending a grid, one hand of cards a turn.

## Features

- Speech output through Prism, with support for common screen readers and speech backends.
- Review buffers for the focused control, your hand, your mech, the invaders, and the fight.
- A context-sensitive key list (F1) that shows only the keys that do something where you are.
