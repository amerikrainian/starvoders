# Controls

Every key the mod binds, by group, as it comes. Keys are keyboard only. F1 shows the subset that does something where you are; that is usually what you want.

## Changing keys

The mod menu's All keys lists the mod's keys by group (Global, Navigation, Fight, Run). Enter on an action opens its keys: Enter on a key replaces or removes it, Add key gives the action another, and Reset to default puts its keys back. A new key is the first one you press, with whatever Ctrl, Shift and Alt you hold; Escape cancels. A key another action of the same group already has is refused, and the capture waits for another. A key used in another group is taken, and you are told what else it does: where both groups are live, the deeper one wins (in a fight, the fight's keys over navigation's). Changes save at once. Reset all keys, at the end of All keys, puts every key back.

Two exceptions:

- The fight keys the game itself binds (the card digits, End turn, the piles, Rewind, More info) follow the game's Options, so they are changed there, and the list says so.
- The mod menu, Enter, Escape, Up and Down always keep at least one key.

## Global

| Key | Function |
| --- | --- |
| F1 | Keys here: the keys that do something on this screen, each runnable with Enter |
| Ctrl+Shift+M | Mod menu |
| Ctrl+Shift+A | Toggle keyboard navigation |

## Navigation

| Key | Function |
| --- | --- |
| Arrows | Move focus; Left/Right change a chooser or slider, or page a row (a pilot, a guide page) |
| Tab / Shift+Tab | Next / previous control group |
| Enter | Activate |
| Backspace | Secondary action: details, where a control has them |
| Escape | Back, cancel, close |
| Home / End | First / last item of the list |
| Alt+Up / Alt+Down | Previous / next section |
| Letters | Type-ahead search in the focused group |

## Buffers

| Key | Function |
| --- | --- |
| Ctrl+Right / Ctrl+Left | Next / previous buffer |
| Ctrl+Up / Ctrl+Down | Next / previous line |

## The Fight: The Game's Keys

These are the game's own actions, so they follow its Controls options. The defaults:

| Key | Function |
| --- | --- |
| 1 to 9, 0 | Play card 1 to 10 |
| Shift+1 to 9, 0 | Read card 1 to 10, as the hand reads it |
| E | End turn |
| A | Draw pile |
| S | Discard pile |
| R | Rewind |
| F | More info, as Backspace |

## The Fight: Glances

| Key | Function |
| --- | --- |
| C | Coordinates of the focused cell |
| T | Turn |
| Ctrl+H | Your energy: Heat, Power and Battery, or Mana and its gain a turn |
| Ctrl+O | Objective |
| Ctrl+M | The mech: its state and tile |
| Ctrl+B | Bombs out of the limit, and Summons |

## The Board

| Key | Function |
| --- | --- |
| Arrows | Move one cell |
| I / K / J / L | As Up / Down / Left / Right |
| U / O / N / M | Move diagonally: up left, up right, down left, down right |
| Shift+Arrows | Skip past cells that read the same |
| Home / End | First / last column of the row |
| Page Up / Page Down | Top / bottom row of the column |
| Shift+M | Go to the mech |
| Alt+H | Go to your hand |
| ] / [ | Next / previous category |
| . / , | Next / previous in the category |
| Alt+Backspace | Jump back to where the last jump left from |
| Enter | Click the tile; while choosing a target, choose it |
| Backspace | The cell's details |
