# Controls

Every key the mod binds, by group. Keys are keyboard only. F1 shows the subset that does something where you are; that is usually what you want.

## Global

| Key | Function |
| --- | --- |
| F1 | Keys here: the keys that do something on this screen, each runnable with Enter |
| Ctrl+Shift+M | Mod menu |
| Ctrl+Shift+A | Toggle keyboard navigation |

## Navigation

| Key | Function |
| --- | --- |
| Arrows | Move focus; Left/Right change a chooser or slider, or page a row (a pilot, a guide page) |
| Tab / Shift+Tab | Next / previous control group |
| Enter | Activate |
| Backspace | Secondary action: details, where a control has them |
| Escape | Back, cancel, close |
| Home / End | First / last item of the list |
| Alt+Up / Alt+Down | Previous / next section |
| Letters | Type-ahead search in the focused group |

## Buffers

| Key | Function |
| --- | --- |
| Ctrl+Right / Ctrl+Left | Next / previous buffer |
| Ctrl+Up / Ctrl+Down | Next / previous line |

## In a Run

Live in a fight, between fights and on the menus over them (pause menu, deck, Compendium).

| Key | Function |
| --- | --- |
| Ctrl+D | Doom |

## The Fight: The Game's Keys

These are the game's own actions, so they follow its Controls options. The defaults:

| Key | Function |
| --- | --- |
| 1 to 9, 0 | Play card 1 to 10 |
| Shift+1 to 9, 0 | Read card 1 to 10, as the hand reads it |
| E | End turn |
| A | Draw pile |
| S | Discard pile |
| R | Rewind |
| F | More info, as Backspace |

## The Fight: Glances

| Key | Function |
| --- | --- |
| C | Coordinates of the focused cell |
| T | Turn |
| Ctrl+H | Your energy: Heat, Power and Battery, or Mana and its gain a turn |
| Ctrl+O | Objective |
| Ctrl+M | The mech: its state and tile |
| Ctrl+B | Bombs out of the limit, and Summons |

## The Board

| Key | Function |
| --- | --- |
| Arrows | Move one cell |
| Shift+Arrows | Skip past cells that read the same |
| Home / End | First / last column of the row |
| Page Up / Page Down | Top / bottom row of the column |
| Shift+M | Go to the mech |
| Alt+H | Go to your hand |
| ] / [ | Next / previous category |
| . / , | Next / previous in the category |
| Alt+Backspace | Jump back to where the last jump left from |
| Enter | Click the tile; while choosing a target, choose it |
| Backspace | The cell's details |
